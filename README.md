# 🌙 مُعبِّر الأحلام — Dreams Interpreter

تطبيق ويب لتفسير الأحلام اعتماداً على **مراجع تفسير الأحلام الإسلامية** (ابن سيرين،
النابلسي). كل حلم محادثة مستقلة تُحفظ بتاريخها، مع لوحة متابعة وملخص عام، وإمكانية
**الإدخال بالصوت**.

## المميزات

- 🔐 **تسجيل/دخول** بحسابات (JWT في httpOnly cookie + bcrypt).
- 💬 **شات تفسير الأحلام** — كل حلم = conversation له سياقه، مؤصّل على قاعدة رموز
  إسلامية كلاسيكية تُحقَن في سياق الـ AI لمنع التأليف.
- 📅 **تتبّع بالتواريخ** — احفظ كل حلم وتاريخه (حتى لو حلم قديم تتذكره).
- 📊 **Dashboard + ملخص عام** — إجمالي الأحلام، أكثر الرموز تكراراً، مزاج الأحلام،
  ونظرة عامة تحليلية.
- 🎤 **إدخال بالصوت** عبر Web Speech API (مجاني، عربي مدعوم).

## التقنيات

- **Next.js 15** (App Router) — full-stack، بيتنشر على Vercel.
- **libSQL / Turso** — قاعدة بيانات SQLite سحابية تشتغل serverless (مجانية).
- **Drizzle ORM** — يسهّل التبديل لـ Postgres لاحقاً لو لزم.
- **مزود AI متوافق مع OpenAI (agnostic)** — OpenAI / Groq / OpenRouter / محلي…
- **Tailwind CSS** — واجهة عربية RTL بمظهر ليلي.

## التشغيل محلياً

```bash
npm install
cp .env.example .env        # واضبط القيم
npm run dev                 # http://localhost:3000
```

> بدون مفتاح `AI_API_KEY` التطبيق يعمل بوضع **fallback** يفسّر من قاعدة الرموز
> المحلية مباشرة (بدون استدعاء خارجي). اضبط المفتاح لتفسير تفاعلي أعمق.

قاعدة البيانات تُنشأ **تلقائياً** عند أول طلب (`CREATE TABLE IF NOT EXISTS`)،
فلا حاجة لخطوة migration منفصلة.

## المتغيّرات البيئية

| المتغيّر | الوصف |
|----------|-------|
| `DATABASE_URL` | `file:local.db` محلياً، أو `libsql://...turso.io` للإنتاج |
| `DATABASE_AUTH_TOKEN` | توكن Turso (للإنتاج فقط) |
| `AUTH_SECRET` | سرّ طويل عشوائي لتوقيع الجلسات (`openssl rand -base64 48`) |
| `AI_API_KEY` | مفتاح المزود (اختياري — بدونه يعمل fallback) |
| `AI_BASE_URL` | عنوان المزود المتوافق مع OpenAI |
| `AI_MODEL` | اسم الموديل |

## النشر على Vercel (مجاناً)

1. أنشئ قاعدة Turso مجانية من [turso.tech](https://turso.tech) واحصل على
   `DATABASE_URL` + `DATABASE_AUTH_TOKEN`.
2. اربط الريبو بـ Vercel، وأضِف المتغيّرات البيئية أعلاه.
3. Deploy — والـ schema يُنشأ تلقائياً عند أول طلب.

## البنية

```
src/
  app/                # صفحات + API routes (App Router)
    api/auth/         # register / login / logout / me
    api/dreams/       # CRUD + الرسائل
    api/summary/      # الملخص العام
  components/         # واجهة العميل (شات، لوحة، إدخال صوتي)
  db/                 # schema + client + إنشاء الجداول
  lib/                # auth, ai, رموز الأحلام, خدمة الأحلام
  data/               # قاعدة رموز الأحلام الإسلامية (JSON)
```
